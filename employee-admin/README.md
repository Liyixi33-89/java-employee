# 员工后台管理系统

Java 学习主线（《01-初级后端工程师（0-1.5年）学习路线》）的贯穿项目。
当前处于 **第一周 / V0.1 起步**：只交付可编译运行的菜单骨架。

## 环境要求

| 项 | 版本 |
|---|---|
| JDK | 21（Temurin 21.0.x LTS） |
| 构建 | 第一周用 `javac` + `java`，V0.2 引入 Maven |
| Git | 任意近期版本 |

## 目录结构

```
employee-admin/
├── src/
│   ├── Main.java          程序入口
│   └── ConsoleMenu.java   菜单循环、输入容错、分支分发
├── build.ps1              编译并运行
└── README.md
```

## 编译与运行

```powershell
cd employee-admin
powershell -File build.ps1
```

`build.ps1` 等价于手工执行：

```powershell
javac -encoding UTF-8 -d out src\*.java
java -Dstdout.encoding=UTF-8 -cp out Main
```

Windows 控制台若中文乱码，先执行 `chcp 65001`。

## 当前已实现

- 菜单循环：1 新增 / 2 列表 / 3 查询 / 4 修改 / 5 删除 / 0 退出。
- 输入容错：字母、空输入、超范围数字、未知选项均给出提示并返回菜单。
- 退出：选择 `0` 或输入流结束（EOF）都干净结束进程。

## 当前不支持（阶段边界，不是隐藏缺陷）

- 业务功能全部为占位提示，数据不落盘，**重启后数据消失**。
- 无员工对象与集合，无唯一性校验（工号重复等规则第二周实现）。
- 无持久化、无数据库、无测试、无日志。
